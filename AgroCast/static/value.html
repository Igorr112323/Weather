Паспорт навыка AgroCast (walk-forward 2005–2024, 28 точек юга России)

загружаю отчёт…

Сегменты

RPSS против равномерной климатологии; «лучше климатологии» — доля отдельных прогнозов с RPS ниже климатического. Навык подтверждён только для температуры.

По годам — сезонная t2m

Каждый год — честный walk-forward: прогноз только по прошлым годам, сверка с фактом.

По годам — месячная t2m (lead 1)

Месячный горизонт: цель — следующий месяц от выпуска.

Декомпозиция — сезонная t2m

Средний RPS по цепочке усложнения прогноза. Строка «жадный климат» оценивает, сколько навыка даёт сам тёплый тренд, а не прогностическая система.

Калибровка — сезонная t2m (продукт)

Заявленная вероятность терцели против фактической частоты; ECE — средняя ошибка калибровки по терцилям.

По сезонам года

Разбивка по сезону целевого месяца.

Честно

Отчёт строится из записей полного аудита «проверки прошлого» (scripts.audit_full grid, 28 ячеек 0.5° Краснодарского края, 2005–2024, 26 880 верификаций). Источник данных — открытые NOAA · NCEP · CPC; продукт не использует чужие прогнозы.
