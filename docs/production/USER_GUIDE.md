# AgroCast — инструкция пользователя

AgroCast — приложение для просмотра сезонных агропрогнозов на своём компьютере.
Расчёты идут локально, данные скачиваются на вашу машину, в интернет приложение
уходит только для первичной загрузки наблюдений (один раз на каждую точку).

**Культура:** кукуруза на зерно. **Регион:** 28 контрольных точек Краснодарского края.

## Что этот продукт НЕ обещает

- **Это не предписание к действию.** Прогноз — ориентировочная вероятностная оценка,
  а не рекомендация сеять, поливать или вносить удобрения.
- **Навык по осадкам не подтверждён.** Прогноз осадков публикуется на уровне
  климатологии и помечается «навык не подтверждён». Решения, зависящие от осадков
  (полив, даты сева), следует принимать по другим источникам.
- **Навык по температуре подтверждён частично.** Сезонная температура (t2m) показывает
  положительный RPSS против климатологии, но это измерение на исторических данных;
  будущая повторяемость не гарантирована.
- **Это не гарантия дохода.** Денежные оценки в отчёте — сценарная модель, не обещание
  прибыли.
- **Агрономические рекомендации не верифицированы экспертом-агрономом.** До завершения
  ручной сверки (чек-лист AGRO_CHECKLIST.md) любые карточки «что делать» публикуются
  с пометкой «ориентировочно, не предписание».
- **Горизонт прогноза — 1–6 месяцев.** За пределами этого диапазона расчёты не
  выполняются.

## Установка из исходников

Требования: Python 3.11 или новее, 4 ГБ свободной оперативной памяти, ~200 МБ на диске.

```bash
git clone https://github.com/Igorr112323/Weather.git
cd Weather
python3 -m venv .venv
.venv/bin/pip install -U pip
.venv/bin/pip install -r AgroCast/requirements.txt
```

На Windows используйте `.venv\Scripts\pip` вместо `.venv/bin/pip`.

## Первый запуск

```bash
cd AgroCast
../.venv/bin/python -m agrocast.desktop
```

Откроется окно с тремя блоками. Если PySide6 не установлен (или запуск на сервере
без графики), сервер поднимется без окна и напечатает URL в терминал — откройте его
в браузере.

### Установка с GUI (опционально)

```bash
.venv/bin/pip install -r AgroCast/requirements-desktop.txt
```

PySide6 ставит QtWebEngine (~300 МБ). После установки `python -m agrocast.desktop`
откроет полноценное окно.

## Как пользоваться

1. **Выберите точку** из списка (28 контрольных точек Краснодарского края).
2. **Выберите месяц выпуска** — до какого месяца у приложения полные данные.
   Пустое поле = последний доступный месяц.
3. **Нажмите «Рассчитать прогноз».** Первый расчёт новой точки занимает 2–6 минут
   (скачивание суточных наблюдений CPC). Повторный расчёт — мгновенно из кэша.
4. **Результат:** вероятности tercile (выше/около/ниже нормы) по температуре и
   осадкам, медиана осадков, полный JSON в раскрывающемся блоке.
5. **Экран данных** показывает все файлы бандла, скачанных наблюдений и кэша с датами.

### Отмена и сроки

- У расчёта есть кнопка «Отменить» — прерывает запрос, уже скачанные данные сохраняются.
- Если расчёт идёт более 10 минут, он прерывается автоматически с сообщением.
- Данные наблюдений помечаются «устарели» при возрасте более 10 минут от момента
  загрузки.

## Где живут данные

Все данные хранятся на вашем компьютере:

| Путь | Содержимое |
|------|------------|
| `AgroCast/world/` | Набор моделей и наблюдений (read-only бандл, ~60 МБ) |
| `~/.agrocast/agrocast.db` | SQLite-база состояния |
| `~/.agrocast/compute/` | Скачанные суточные наблюдения |
| `~/.agrocast/results-v1/` | Кэш рассчитанных прогнозов |
| `~/.agrocast/desktop-releases.json` | Отпечатки версии бандла |

Путь `~/.agrocast` можно переопределить переменной `AGROCAST_DESKTOP_HOME`.

## Обновление данных

Наблюдения обновляются при расчёте: если у CPC появились новые дни, приложение
докачивает их идемпотентно (повторный запуск не дублирует данные). Прерванная
загрузка не портит предыдущий снимок.

Наборы моделей (bundle release-ы) обновляются контент-адресно: новый release
публикуется с SHA-256 каждого файла, активируется только после полной проверки
и атомарно переключает указатель. Откат: `python -m scripts.bundle_publish rollback`.

## Печать и мобильный экран

- **Печать:** Ctrl+P → A4, кнопки и навигация скрываются, результат выводится
  на бумагу.
- **Мобильный экран:** раскладка адаптируется к ширине ≤700px.
- **Клавиатура:** Tab/Shift+Tab для навигации, Enter для выбора, focus-visible
  обводка.

## Ограничения и известные проблемы

- **Подпись/нотаризация:** бинари не подписаны кодом. Windows SmartScreen и macOS
  Gatekeeper могут показать предупреждение — используйте правый клик → «Открыть».
  Это не вирус — антивирус реагирует на неподписанный PyInstaller-бинарь.
- **Только 28 точек КРА:** произвольные координаты России не поддерживаются.
- **Только кукуруза на зерно:** другие культуры не включены.
- **Нет автообновления:** новую версию приложения нужно скачивать вручную.
- **Осадки:** навык не подтверждён; рекомендации по поливу строятся на ET0
  (температурный дефицит), а не на прогнозе осадков.

## Проверка подлинности и безопасности

### SHA-256 архивов

Скачав архив из GitHub Releases, сверьте контрольную сумму:

**Windows:**
```
certutil -hashfile AgroCast-windows-x64.zip SHA256
```

**macOS/Linux:**
```
sha256sum AgroCast-linux-x64.zip
```

Сравните результат с файлом `SHA256SUMS` в релизе.

### Целостность данных

При запуске приложение автоматически проверяет SHA-256 набора данных
(`world/integrity.json`). Если данные повреждены или изменены — приложение
не запустится и покажет ошибку.

### Что программа НЕ делает

- **Не отправляет данные в интернет** — все расчёты локальны
- **Не содержит eval/exec** — никаких скрытых скриптов
- **Не использует CDN** — все стили и скрипты встроены
- **Не пишет в localStorage** — данные только в файловой системе
- **Не содержит subprocess** для внешних команд (кроме изолированного
  sandbox-воркера с seccomp и RLIMIT)
- **Все внешние URL** — только NOAA/Copernicus (обновление данных,
  отключено в desktop-режиме для точек из bundle)

## Проверки

Полный тестовый набор:

```bash
cd AgroCast
../.venv/bin/python -m pytest tests -q
```

Ожидаемый результат: **669 passed, 20 skipped** (скипы — browser и PostgreSQL-флаги).

Смоук встроенного сервера:

```bash
cd AgroCast
../.venv/bin/python -c "
from agrocast.desktop.app import prepare_environment, start_server
import json, urllib.request
prepare_environment('smoke')
server, thread, url = start_server()
try:
    payload = json.load(urllib.request.urlopen(url + 'api/capabilities', timeout=15))
finally:
    server.should_exit = True
    thread.join(timeout=15)
assert payload['operations']['local_mode']
print('ok')
"
```

Приложение использует открытые данные:

- **ERA5** (Copernicus/ECMWF) — атмосферные переменные; условия использования:
  [Copernicus License](https://cds.climate.copernicus.eu/api/v2/terms/static/licence.pdf)

- **NOAA NCEP** — стратосферные данные; public domain.
- **NOAA OISST** — температура поверхности океана; public domain.

Полный инвентарь прав: [DATA_LICENSES.md](DATA_LICENSES.md).

## Вердикт готовности

**Локальный десктоп-пилот: годен.** Приложение запускается, рассчитывает, кэширует,
отменяется, печатается. Научный навык по температуре — положительный (измерено на
исторических данных), по осадкам — не подтверждён.

**Публичный веб-сервис: NO-GO.** Веб-контур остаётся в режиме закрытого пилота;
научные и release gates не пройдены.

**Агрономические рекомендации: не верифицированы.** До заполнения
AGRO_CHECKLIST.md экспертом-агрономом рекомендации публикуются только как
ориентировочные.
