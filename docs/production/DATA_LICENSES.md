# Инвентарь прав и способов поставки данных (T23)

Дата составления: 2026-09-07. Статус документа: **подготовлен к юридической
проверке**; правки владельца/юриста обязательны перед внешним релизом —
юридическая применимость условий на эту дату не предполагается.

## Модель поставки (одно-машинная)

Приложение устанавливается пользователю; «свежие» наблюдения приложение качает
**с компьютера пользователя напрямую с открытых источников** — продукт не
ретранслирует и не распространяет их файлы. В составе продукта переносится только
seed-bundle (агрегированные решёточные производные), права на него — в таблице ниже.

## Приватность и пользовательские данные (проверено тестами)

- Десктоп: поля и история расчётов живут только на машине пользователя
  (`state_dir`; поля — localStorage браузера приложения). Серверов оператора нет;
  телеметрии нет.
- Веб-контур (пилот): пароль — argon2id, сессии — cookie HttpOnly/Secure (T02–T03);
  добавлен **полный экспорт** `GET /api/account/export` (все свои fields/crops/
  subscriptions/jobs/publications, без хэшей паролей) и **безвозвратное удаление**
  `DELETE /api/account` с обязательным повторным вводом пароля: каскад ресурсов,
  сессий и организации при отсутствии других пользователей; активная задача
  запрещает удаление (409). Проверено `tests/test_account_privacy_t23.py`
  (экспорт не содержит секретов; чужие пользователи организации не затрагиваются).
- Ретенция: очередь/журналы имеют retention (T06–T07); локальный стейт удаляется
  вместе с каталогом `state_dir` (CLI `agrocast.state.cli` backup/restore — T05).

## Условия использования продукта (что уже в интерфейсе/API)

- no-skill/«навык не подтверждён», stale-цен, «сценарная оценка, не гарантия
  дохода», «ориентировочно — не предписание» (T11–T12) — тексты публикуются в
  payload и digest; закрытый пилот гейтит вычисления на сервере (T01).
- Для внешнего релиза требуется утверждённый текст «что продукт не обещает»
  (часть T24 release review); без него — не включать.

## Критерии, которые этот документ закрывает и не закрывает

Закрывает: инвентарь составлен; способ поставки каждого источника явный;
экспорт/удаление реализованы и проверены тестами.
Не закрывает (остаются блокирующими для внешнего релиза): юридическая проверка
Copernicus-атрибуции и цитирования норм; выбор лицензии кода; согласование
текста условий использования PO/юристом.
