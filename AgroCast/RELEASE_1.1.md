- **Было:** использовался только внешний OSM тайл-слой https://tile.openstreetmap.org — без интернета карта была серой, точки не выбирались, клики не работали.

## Как запустить 1.1

```bash
python3 -m venv .venv
.venv/bin/pip install -U pip
.venv/bin/pip install -r AgroCast/requirements.txt
cd AgroCast
../.venv/bin/python -m agrocast.desktop
# или
../.venv/bin/python app.py
```

Откроется окно с картой. Выберите точку, месяц, сорт кукурузы → «Показать прогноз».
