## Исключено из релиза до верификации (решение T12)

- **Запас влаги корнеобитаемого слоя из ERA5 `swvl1` (слой 0–7 см).**
  Ранее: `reserve = (θ−0.10)·2000 мм` завышал доступную влагу в ~20 раз.
  Теперь публикуется только θ-индикатор поверхности (`surface_theta`),
  кредит запаса = 0 (консервативно: норма полива = полный дефицит
  водобаланса). Возврат возможен после верификации агрономом
  многослойных данных или явного коэффициента слоя.

- **Предписания по tp (полив, орошение, «действовать» по риску засухи)**
  выдаются только при подтверждённом навыке tp; на 2026-09-07 навык tp
  не подтверждён (grid-skill-v2: RPSS −0.106, CI [−0.165, −0.039]) —
  все предписания по tp публикуются с маркировкой «ориентировочно,
  не предписание».

## Правила, подлежащие подтверждению экспертом

1. **Декадная дезагрегация полива:** сумма p50 декад ≥ сезонной медианы
   (квантиль суммы ≠ сумма квантилей) — принято как консервативная
   оценка; эксперт подтверждает допустимость или требует распределения.

2. **«Сухой сценарий» полива:** ET0 p90 − осадки p10 (не перцентиль
   одного распределения) — подтверждение формулировки для фермера.

3. **Окупаемость/«на грани»** — сценарная оценка (money_note публикуется
   в API и digest); гарантия дохода не обещается ни в одном тексте.

4. **Связь поля и точки:** forecast-запрос по координатам поля, ответ
   содержит `lat/lon` поля и ближайший узел сетки `grid_point` (проверено
   тестом интеграции с bundle).
