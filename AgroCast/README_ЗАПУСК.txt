AgroCast — сезонный агропрогноз для России (автономный продукт)
=================================================================

ЗАПУСК
  1. Распакуйте папку AgroCast в любое место.
  2. Нужен Python 3.11+.
  3. Запуск:  python app.py
     — при первом запуске сам установит зависимости (numpy, pandas, xarray,
       zarr, scikit-learn, lightgbm, fastapi, uvicorn и др.),
     — поднимет локальный сервер и открыет карту в браузере.
     Ручной вариант:  pip install -r requirements.txt
                      uvicorn agrocast.serve.product:app --port 8501

КАК ПОЛЬЗОВАТЬСЯ
  — Кликните точку на карте России (вне территории — продукт откажет).
  — Выберите месяц: будущий — прогноз, прошлый (2008–2024) — проверка прошлого.
  — Отчёт: декады, вода и полив (м³/га), САТ по культурам, фено-календарь,
    риски с действиями, аналоги-годы, деньги (₽/га), паспорт доверия.
  — «Мои поля»: добавьте свои поля на главной странице (хранятся в браузере) —
    отчёт посчитает полив в м³ и риск в ₽ на каждое поле.

ПОЧТОВЫЙ ДАЙДЖЕСТ ПО ПОЛЯМ
  fields.json рядом с app.py (или свой файл):
    [{"name": "Кубанское", "crop": "winter_wheat", "area": 120, "lat": 45.03, "lon": 39.07}]
  Культуры: winter_wheat, winter_barley, sunflower, maize, soy, rapeseed, sugar_beet.
  Проверка письма:  python -m agrocast.serve.digest --fields fields.json --dry-run
  Отправка:        AGROCAST_SMTP_HOST=... AGROCAST_SMTP_PORT=587 \
                   AGROCAST_SMTP_USER=... AGROCAST_SMTP_PASS=... \
                   python -m agrocast.serve.digest --fields fields.json --to a@b.ru

ЧЕСТНОСТЬ
  Все вероятности — собственный ансамбль без чужих прогнозов; навык проверен
  walk-forward за 17 лет и показан в отчёте (паспорт доверия). Цены — Росстат
  (январь 2026) и рыночные ориентиры; расчёт убытков — ориентир, не котировка.

ОБНОВЛЕНИЕ ДАННЫХ
  Снеговой покров (открытый NOAA CDR, 1966–наст., без ключей):
      python -m agrocast.ingest.snowcdr --world world
  Прогноз пересчитывается на актуальном снеге: чем снежнее зима вокруг поля,
  тем холоднее и влажнее ожидается весна (драйвер «Снежный покров» в отчёте).
